# Smart Recycling Bin (스마트 자동 분리수거 쓰레기통)

> **객체 인식 AI와 센서 융합을 활용한 자동 폐기물 분류 및 적재 관리 임베디드 시스템

## 1. Project Overview (프로젝트 개요)

* **개발 기간**: 2026.03 ~ 2026.06
* **개발 배경**: 
  * 분리배출 시 낮은 선별 정확도와 수거 인력의 관리 비효율을 개선하고자 제작한 캡스톤 디자인 프로젝트 입니다.
  * 투입된 폐기물을 센서로 감지하면 상위 AI 모델의 판별 결과에 따라 모터와 액추에이터를 구동해 4개 품목(일반, 플라스틱, 캔, 유리)으로 자동 분류하고 수거함별 적재량을 관리합니다.
* **주요 역할 (Firmware & Control Logic)**:
  * ATmega2560 메인 제어기 시퀀스 펌웨어 설계 및 구현
  * `Timer2` 하드웨어 인터럽트를 활용한 시스템 생존 신호(Heartbeat) 모니터링 체계 구축
  * 시프트 레지스터(`74HC595`) 제어로 MCU GPIO 핀 소모 최소화
  * X축 주행 DC 모터의 소프트웨어 PWM 속도 제어 및 상태 머신 기반 위치 추적
  * 상위 엣지 AI 프로세서와 `115200 bps` UART 시리얼 프로토콜 규격 수립

## 2. System Architecture & Workflow (동작 프로세스)

### Step 1. 대기 및 투입 감지
* 안전 게이트 개방 대기 (`gateOpen`)
* 투입구 IR 센서(`Trash_IR_IN`) 감지 즉시 안전 게이트 폐쇄 (`gateClose`)
* 상위 AI 프로세서로 시리얼 신호 송신 (`TRASH_DETECTED\n`)

### Step 2. 비전 AI 판별 결과 수신 (UART)
* 상위 장치로부터 분류 결과 문자열 수신 (`GENERAL`, `PLASTIC`, `CAN`, `GLASS`)
* 분류 품목에 해당하는 상태 표시 LED 점등 (`LED_GENERAL`, `LED_PLASTIC`, `LED_CAN`, `LED_GLASS`)

### Step 3. 내부 낙하 및 X축 슬롯 이동
* 내부 낙하 도어 서보 개방 (`trashDoorOpen`) -> 1.5초 후 복귀 폐쇄 (`trashDoorClose`)
* X축 IR 센서(`X_MOVE_IR_PIN`) 폴링 엣지 카운트로 목표 슬롯까지 주행 (`moveToPosition`)
  * **GENERAL**: `0 Count` (원점)
  * **PLASTIC**: `2 Count`
  * **CAN**: `3 Count`
  * **GLASS**: `4 Count`

### Step 4. 액추에이터 압입 및 원점 복귀
* 74HC595 시프트 레지스터 비트 제어로 선형 액추에이터 전진(3초) -> 정지(0.5초) -> 후진(3초) 구동 (`runActuator`)
* 이동한 카운트만큼 DC 모터를 역회전해 원점(GENERAL 위치)으로 복귀 (`returnToGeneral`)

### Step 5. 4채널 적재율 계측 및 시스템 리셋
* 4개 슬롯 초음파 센서 연속 거리 측정 (`CHO_SEN_1 ~ 4`)
* 빈 공간 기준(30cm) ~ 가득 참(5cm) 범위를 `0 ~ 100%` 적재율로 환산 (`calculatePercentage`)
* 적재 데이터 시리얼 전송, 상태 LED 소등 (`allOff`), 투입구 게이트 재개방 (`gateOpen`)

## 3. Hardware Configuration & Pinout (하드웨어 핀맵)

### 3.1 Hardware Components
* **Main Controller**: Arduino Mega (ATmega2560)
* **Sensors**: 투입 감지 IR 센서, X축 위치 감지 IR 센서, 초음파 센서(HC-SR04) 4개, 금속 센서, 압력 센서
* **Actuators**: 서보 모터(MG996R/SG90급) 3축, X축 구동 DC 모터 2채널, 선형 푸시 액추에이터
* **IC & Logic**: 74HC595 시프트 레지스터 (모터 제어 핀 확장용)

## 4. Serial Communication Protocol (UART 통신 규격)

* **통신 인터페이스**: Hardware Serial (UART)
* **통신 속도 (Baud Rate)**: `115200 bps`
* **패킷 규격 및 데이터 흐름**:

| 통신 방향 | 패킷 (Command / Data) | 설명 및 동작 |
| :---: | :--- | :--- |
| **MCU -> Host** | `SYSTEM READY` | 아두이노 전원 인가 및 주변 장치 초기화 완료 알림 |
| **MCU -> Host** | `SYSTEM RUNNING` | `Timer2` 인터럽트 기반 주기적 생존 신호(`Heartbeat`) 전송 |
| **MCU -> Host** | `TRASH_DETECTED` | 투입구 IR 센서 감지 시 상위 비전 AI에 추론 트리거 요청 |
| **Host -> MCU** | `GENERAL\n`, `PLASTIC\n`, `CAN\n`, `GLASS\n` | 비전 모델 객체 판별 결과 명령 수신 (개행 문자 포함) |
| **MCU -> Host** | `GENERAL : X%, PLASTIC : Y%, CAN : Z%, GLASS : W%` | 분류 시퀀스 완료 후 4개 수거함 잔여 적재율 보고 |

## 5. Key Engineering Features (핵심 기술 구현)

* **Timer2 하드웨어 인터럽트를 활용한 비동기 시스템 모니터링**
  * 메인 루프 블로킹 지연과 무관하게 동작하도록 8비트 하드웨어 타이머(`Timer2`) 레지스터(`TCCR2A`, `TCCR2B`, `TCNT2`)를 직접 제어
  * 약 1ms 주기 오버플로우 인터럽트 및 500ms 단위 카운팅 플래그(`printFlag`)로 통신 무결성 및 시스템 생존 신호(`Heartbeat`) 감시

* **소프트웨어 PWM 기법을 활용한 DC 모터 속도 제어**
  * 하드웨어 PWM 채널을 아끼고 급격한 기동 시 기구부가 튀는 현상(오버슈트)을 방지하고자 소프트웨어 펄스 듀티 제어 적용
  * `MOTOR_ON_DELAY(6ms)`와 `MOTOR_OFF_DELAY(4ms)`를 교차 구동하여 감속 구간과 레일 주행 관성을 안정적으로 제어

* **시프트 레지스터(74HC595) 직렬 제어로 GPIO 핀 절약**
  * 리니어 액추에이터 제어 시 MCU I/O 핀 소모를 줄이기 위해 3선식 통신(`MOTOR_SHIFT_DATA`, `CLK`, `STR`) 적용
  * `shiftOut()` 함수와 비트 연산(`bitSet`, `bitClear`)으로 모터 드라이버 제어 신호를 1바이트 상태값(`registerState`)으로 통합 관리

* **상태 머신(State Machine) 기반 엣지 트리거 위치 추적**
  * X축 이동 시 단순 레벨 폴링 대신 `lastIR` 상태 머신을 적용해 진동 노이즈(채터링) 필터링
  * `HIGH -> LOW` 하강 엣지만 유효 카운트로 인식해 목표 슬롯 정지 위치를 맞추고, `returnToGeneral` 함수로 동일 카운트만큼 역회전해 원점으로 복귀

## 6. Engineering Notes (하드웨어 디버깅 및 이슈 해결)

* **`delay()` 블로킹 제거 및 ATmega 하드웨어 타이머(`Timer2`) 비동기 제어**
  * **기존 문제점**: 
    * 초기에는 상위 프로세서에 주기적으로 생존 신호(`"SYSTEM RUNNING"`)를 전송하려고 `delay(1000)`을 사용했습니다. 그러나 `delay()` 동작 중 메인 루프가 정지되어 투입구 IR 센서(`Trash_IR_IN`) 감지와 시리얼 수신(`serialEventProcess()`)이 지연되는 블로킹 문제가 발생했습니다.
  * **원인 분석 및 해결**: 
    * 단순 소프트웨어 딜레이 대신 8비트 하드웨어 타이머인 **Timer2 오버플로우 인터럽트**를 활용해 주기적 신호 발생 로직을 메인 루프와 분리했습니다.
    * 16MHz 클럭 환경에서 `TCCR2B = 0x05`(128 분주비)로 설정하고, 카운터 레지스터에 `TCNT2 = 6`을 프리로드(256 - 6 = 250 카운트)해 약 **2ms 주기마다 타이머 오버플로우 인터럽트(`TIMER2_OVF_vect`)**가 정확히 발생하도록 레지스터를 직접 세팅했습니다.
    * ISR 내부에서는 카운트 연산(`timerCount++`)만 가볍게 처리하고, 500회 누적(약 1초) 시 비동기 플래그(`printFlag = true`)를 올려 메인 루프에서 비차단(non-blocking) 방식으로 신호를 전송하도록 구현했습니다.
    * 그 결과 CPU 점유율 낭비 없이 센서 감지 반응성과 통신 신뢰성을 모두 확보했습니다.

* **초음파 센서 연속 계측 간 잔류 음파 간섭 해결**
  * 초음파 센서 4개(`CHO_SEN_1 ~ 4`)를 연달아 트리거할 때 이전 센서의 반사파 잔향이 인접 센서의 ECHO 핀으로 들어와 측정값이 튀는 현상이 발생했습니다.
  * 각 채널 계측 사이에 30ms(`delay(30)`)의 안정화 간격을 두어 공간 내 잔류 음파가 충분히 감쇠된 뒤 다음 센서를 측정하도록 시퀀스를 보정했습니다. 이를 통해 4개 수거함에 대해 안정적인 거리 측정값과 0~100% 적재율(`calculatePercentage`) 신뢰도를 확보했습니다.

* **DC 모터 주행 진동 노이즈(채터링)로 인한 위치 카운트 오차 방지**
  * 카트가 레일을 주행할 때 발생하는 기계적 진동으로 IR 위치 센서(`X_MOVE_IR_PIN`) 입력이 튀어, 슬롯 카운트가 중복 계산되면서 목표 위치를 지나치는 문제가 발생했습니다.
  * 단순 레벨 체크 대신 이전 상태값(`lastIR`)을 비교하는 엣지 검출 로직(`val == LOW && lastIR == HIGH`)과 100ms 디바운스 필터를 적용했습니다.
  * 하강 엣지만 유효한 슬롯 카운트로 인식하도록 개선해 목표 지점 도달(`moveToPosition`) 및 원점 복귀(`returnToGeneral`) 시의 위치 정밀도를 확보했습니다.
